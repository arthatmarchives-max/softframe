# softframe

Static story-template app. No build step or backend required.

## GitHub Pages
Upload the contents of this folder to the repository root (so index.html is at the top level).
In Settings > Pages, choose Deploy from a branch, branch `main`, folder `/(root)`.
This package uses relative paths and is designed to work from a GitHub Pages project URL.

## Install
Open the published HTTPS URL in Chrome on Android and choose Install app / Add to Home screen.
On iPhone, use Safari > Share > Add to Home Screen. iOS may describe this as a home-screen app rather than a separate install button.

The app shell and templates are cached for offline use after the first successful visit. Google Fonts are external and may not load offline.
